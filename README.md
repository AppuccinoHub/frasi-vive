# Frasi Vive · Il sabato di Giulia

A 10-card Italian 3 Honors pilot built on **phrase chunks**: students listen to a whole Italian phrase, read it, rebuild or type it, and say it out loud.

**Open it:** https://appuccinohub.github.io/frasi-vive/

- One self-contained file (`index.html`): art, audio and code are all inside it. Save it and it works offline, even opened from Downloads.
- The only network use: when a student taps **Play** on a song card, the app streams Apple's 30-second preview (courtesy of Apple Music). If a school network blocks that, the card still works.
- No logins, no names, no tracking. Progress stays in the browser (localStorage). Voice recordings stay on the device and are never saved or sent.

**Content:** presente, imperfetto, passato prossimo; io / tu / lui-lei only; regular verbs plus essere and avere.
Levels: 1 = word tiles (Sono / Ero / Sono stata al centro commerciale), 2 = listen and type the missing words (includes 2 song cards), 3 = type the whole phrase from English.

Illustrations: original vector art made for this app. Italian voice: Kokoro-82M (Apache-2.0), voice `if_sara`, generated offline.
